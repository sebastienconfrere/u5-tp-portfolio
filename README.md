# TP — Prise en main du portfolio E5

Ce dépôt contient **le matériel du TP** : un profil fictif et deux situations. Vous ne modifiez rien ici. Vous copiez le texte, et vous le collez dans **votre** portfolio.

## Ce que vous devez rendre

Deux adresses, dans le devoir Teams :

1. l'adresse de **votre portfolio** : `https://votrepseudo.github.io`
2. l'adresse de **la page du TP** que vous aurez créée : `https://votrepseudo.github.io/tp-camille.html`

## Avant de commencer — trois vérifications

1. Ouvrez `https://github.com/votrepseudo/votrepseudo.github.io`. En haut à gauche, vous devez lire **votre pseudo / votrepseudo.github.io**. Si vous lisez `sebastienconfrere`, vous êtes sur le modèle : revenez sur votre dépôt.
2. Sous le nom du dépôt, le libellé doit être **Public**. S'il indique *Private*, allez dans **Settings > General**, tout en bas, section *Danger Zone*, **Change visibility**.
3. Le sélecteur en haut à gauche de la liste des fichiers doit afficher **main**. C'est la branche sur laquelle vous travaillez.

## Étape 1 — Copier le profil fictif

1. Dans **ce** dépôt, ouvrez le fichier `profil-camille.md`.
2. Cliquez le bouton **Raw**, en haut à droite du fichier.
3. Sélectionnez tout (Ctrl + A, ou Cmd + A sur Mac) et copiez (Ctrl + C / Cmd + C).

## Étape 2 — Créer la page du TP dans votre dépôt

1. Retournez sur **votre** dépôt `votrepseudo.github.io`.
2. Cliquez le bouton **+** situé à droite de *Go to file*, puis **Create new file**.
3. Dans le champ du nom, tapez exactement : `tp-camille.md`
4. Collez le texte copié (Ctrl + V / Cmd + V).
5. Cliquez l'onglet **Preview** pour vérifier le rendu : vous devez voir des titres, pas des dièses.
6. Cliquez le bouton vert **Commit changes...** en haut à droite.
7. Dans la fenêtre **Commit changes**, laissez le message proposé, vérifiez que **Commit directly to the main branch** est bien sélectionné, puis cliquez **Commit changes**.

## Étape 3 — Créer la page de situation

1. Revenez dans ce dépôt, ouvrez `situation-a.md`, bouton **Raw**, tout sélectionner, copier.
2. Dans votre dépôt : **+** > **Create new file**, nom du fichier : `tp-situation-a.md`
3. Collez, vérifiez avec **Preview**, puis **Commit changes...** et **Commit changes**.

## Étape 4 — Vérifier que les deux pages sont en ligne

1. Attendez 1 à 3 minutes : GitHub fabrique les pages.
2. Ouvrez `https://votrepseudo.github.io/tp-camille.html` — **avec un h à html**, même si votre fichier s'appelle `.md`.
3. Cliquez le lien *Situation A* : il doit ouvrir `tp-situation-a.html`.
4. Sur la page de situation, cliquez *← Retour au portfolio* : il doit revenir sur `tp-camille.html`.
5. Si vous obtenez une page 404, attendez une minute de plus et rechargez avec Ctrl + F5 (Cmd + Maj + R sur Mac).

## Étape 5 — L'exercice de rédaction

Ouvrez `situation-b.txt` : c'est un récit brut, en langage parlé. Réécrivez-le dans votre page `tp-situation-a.md`, sous un titre `## Situation B`, en respectant la trame : contexte, problématique, démarche, outils mobilisés, précautions prises, résultats, bilan personnel.

Trois règles : au moins un chiffre dans les résultats, au moins une option écartée avec son critère, et pas une seule phrase que vous ne sauriez pas défendre à l'oral.

## Étape 6 — Déposer

Dans le devoir Teams **« U5 · Portfolio — URL »**, déposez les deux adresses : celle de votre portfolio, et celle de `tp-camille.html`.

## Si quelque chose ne va pas

- **Page 404** : le dépôt est privé, ou son nom n'est pas exactement `votrepseudo.github.io`, ou la publication n'est pas terminée.
- **Le texte s'affiche avec des dièses** : le fichier n'a pas l'extension `.md`. Ouvrez-le, cliquez le crayon, corrigez le nom dans le champ en haut.
- **Vous avez cassé une page** : onglet **History** du fichier, ouvrez la version précédente, bouton **...** puis *Revert*. Rien n'est jamais perdu.
